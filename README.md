## Aviation Data Project #1

A real-world ADS-B aviation monitoring and analysis platform built using RTL-SDR, readsb, OpenSky Network, Python and web-based visualization tools.

## Project Objective

The purpose of this project is to explore real-world aviation data collected using ADS-B technology and analyze aircraft operations.

## Data Sources

- RTL-SDR Receiver
- ADS-B Messages
- readsb Decoder
