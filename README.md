# Aviation Data Project #1

## Project Status
🚧 In Development

## Project Objective
The purpose of this project is to explore real-world aviation data and better understand how aircraft operate within modern air traffic systems.
Using ADS-B technology, flight tracking tools, and data analysis, I aim to investigate patterns in aircraft operations and learn how aviation data can be used to better understand flight behavior.

## Research Question
What can real-world aircraft data reveal about aviation operations and air traffic activity?

## What I Hope To Learn
Through this project, I hope to better understand:
- How aircraft transmit flight information.
- How ADS-B technology works.
- How aviation data can be collected and analyzed.
- How data analysis can be used to better understand flight operations.
- How engineers and aviation professionals use operational data.
