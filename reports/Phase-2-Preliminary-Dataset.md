## Preliminary Dataset

The station has already collected multiple days of real-world ADS-B telemetry data.

Current datasets include:

- ADS-B aircraft messages
- Aircraft position reports
- JSON telemetry feeds
- Historical CSV logs
- OpenSky Network contribution data
- Raw hexadecimal ADS-B messages
- 🚧 Preliminary Analysis in Progress

### Raw ADS-B Data Processing

In addition to decoded aircraft telemetry, the station records raw ADS-B hexadecimal messages that can later be used for protocol analysis, decoding validation, and aviation data research.
